# Pattern 6: Inverted Right Triangle with Numbers

**Source:** Striver's A2Z DSA Sheet — Step 1 (Basics) → Pattern Problems

## Problem
Given an integer `n`, print the following pattern.

## Example
Input: `n = 4`
```
1234
123
12
1
```

## Approach
Same as Pattern 5, but print (j + 1) instead of '*' so each row counts up from 1 to the number of stars in that row.

## Complexity
- **Time Complexity:** O(n^2)
- **Space Complexity:** O(1)
