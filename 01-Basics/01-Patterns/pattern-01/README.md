# Pattern 1: Solid Square (Rectangle) Pattern

**Source:** Striver's A2Z DSA Sheet — Step 1 (Basics) → Pattern Problems

## Problem
Given an integer n , print the following pattern.

## Example
Input: n = 4
```
****
****
****
****
```
## Approach
Run two nested loops, both from 0 to n. The outer loop controls the number of rows, and the inner loop prints n stars in every row.

## Complexity
- **Time Complexity:** O(n^2)
- **Space Complexity:** O(1)
